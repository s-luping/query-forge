新增行级规则
使用说明

行级过滤会在 SQL 执行前自动注入 WHERE 条件，限制用户只能看到满足条件的数据行。

例如：为用户设置 employees 表的 dept_id = 10，则该用户查询时生成的 SQL 会自动追加 AND dept_id = 10。

管理员不受行级规则限制。
