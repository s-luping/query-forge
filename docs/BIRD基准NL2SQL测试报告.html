过程发现的问题

  • 已修复缺陷: 创建对话接口在响应序列化阶段引用了 request.schema_name（应为 payload.schema_name），导致每轮首轮生成在全部成功后仍返回 500，前端拿不到 SQL 与结果。 已修复 app/routers/conversation_router.py 并经本轮验证。
  • 已知问题 1: 同步任务 run 状态恒为 failed——元数据同步实际成功（表/列全部入库）， 但收尾阶段抛 DbSchema not bound to Session，建议排查 services/sync_engine.py 会话管理。
  • 已知问题 2: 信息不足拦截（5 题）集中在 need_more_info 分支，其中 formula_1 challenging 3 题全部拦截，复杂多表链路的字段召回有提升空间。
  • 已知问题 3: 火山方舟账号 doubao 系列模型配额耗尽（pro 与 turbo 先后被暂停）， 影响长基准测试连续性。
